1. Overview

FEL International Shipping is a logistics and freight-forwarding partner operating between India, the UAE, the wider GCC, and the rest of the world. The new website is built to mirror the existing brand language (deep navy, sky-blue accent, dotted-world-map iconography) while modernising the page architecture, visual hierarchy, and conversion paths.

This document is the single source of truth for the website build — covering brand system, every section's content, technical decisions, and rollout notes.

Goals

  • Position: Position FEL as a modern, trustworthy, multi-modal freight specialist.
  • Convert: Drive quote requests via prominent contact and floating WhatsApp CTAs.
  • Showcase: Showcase service breadth (Air / Sea / Land / Customs / Warehousing / Personal).
  • Reach: Demonstrate network reach with an animated hub-and-lane world map.
  • Trust: Establish credibility through counters, testimonials, and a clear process.

  • Display: Manrope (700 / 800) — headings, large display text, statistics.
  • Body: Inter (300 / 400 / 500 / 600 / 700) — body, navigation, UI labels.
  • Tracking: Letter-spacing of 0.14–0.22em on uppercase eyebrows and labels.

2.3 Logo

The FEL logo is recreated as inline SVG inside the site. This keeps the wordmark crisp at any size, allows colour switching for dark/light backgrounds via a CSS custom property, and avoids raster assets entirely.

  • Charcoal grey "FEL" wordmark (white on dark backgrounds).
  • Blue swoosh arrow passing through the "L" — signature element.
  • "INTERNATIONAL SHIPPING" wordmark in tracked-out sky-blue caps.
  • Three diagonal speed lines (2 grey, 1 blue) beneath the wordmark.

2.4 Visual Motifs

  • Hero: Dotted world map overlay in the hero (radial-mask, 22px grid).
  • Eyebrows: Short dash + uppercase + small plane (✈) icon.
  • Headings: Two-line H2 with the second line highlighted in sky-blue + underline.
  • Buttons: Pill-shaped CTAs with arrow → that slides on hover.
  • Cards: Glassmorphic country cards in the hero, animated swoosh hubs on the map.

5. Technical Notes

  • Stack: Single static index.html — embedded CSS and vanilla JS, zero dependencies.
  • CSS: Custom properties for the entire brand palette (easy theming).
  • JS: IntersectionObserver-driven reveal animations and counter ramp-ups.
  • Layout: Mobile-first responsive grid; mobile hamburger drawer; smooth-scroll anchors.
  • Icons: Inline SVG (Feather-style) — no icon-font dependency.
  • Fonts: Inter + Manrope via Google Fonts with preconnect.
  • Images: Unsplash placeholders — swap with branded photography in v1.1.
  • Forms: Demo handler on the contact form; wire to your CRM / Mailgun / Zoho before launch.
  • A11y: Semantic landmarks, aria-labels on icons, visible focus rings, 4.5:1 contrast.

Performance targets

  • LCP: < 2.5s on 4G mobile (hero is gradient/dots — no external image).
  • CSS size: < 30KB gzipped.
  • JS: No render-blocking JS — scripts at end of body.
