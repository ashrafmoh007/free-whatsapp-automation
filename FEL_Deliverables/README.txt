FEL INTERNATIONAL SHIPPING — DELIVERABLES PACKAGE
===================================================

Contents
--------
1. index.html              — The website. Open in any browser.

2. FEL_Website_Spec.html   — Spec doc, browser-openable. Print to
                             PDF from your browser if you need a
                             PDF version (Ctrl/Cmd + P).
   FEL_Website_Spec.docx   — Same content, native Word format.

3. FEL_Pitch.html          — Pitch deck, browser-openable. Arrow
                             keys or click left/right edges to
                             navigate. F-key icon → fullscreen.
                             Print to PDF for a static deck.
   FEL_Pitch.pptx          — Same deck, native PowerPoint format.

The .html files are the most portable — they need nothing but a
browser. Use them if the .docx / .pptx are giving you trouble.
